# frontend/ — Anecho desktop UI

Tauri 2 + Svelte 5 (runes) + TypeScript. A pure display client of the WebSocket API:
it sends commands and draws what it receives. No FFT, smoothing or interpolation happens
here (CLAUDE.md rule 2) — level, RTA and scope frames arrive ready to plot, with their
axes in `StartStreamResponse`.

## Layout

```
src/
  lib/client.ts            WebSocket client (protobuf envelopes + binary frames)
  lib/wire.ts              binary frame decoding (layout from contract/anecho.proto)
  lib/stores.svelte.ts     application state: session, tabs, streams, measure, events
  lib/generator.svelte.ts  generator settings -> contract Generator message
  components/
    Graph.svelte           uPlot wrapper (log/linear X, dB Y, cursor readout, bars)
    DevicePicker / SessionPanel / GeneratorPanel   the capture rail
    LevelMeters / RtaTab / ScopeTab                the graph tabs
    Inspector / MeasurePanel                       right-hand inspector
    StatusBar
  gen/                     generated by `make generate` (never edited)
mock/server.ts             hardware-free mock backend speaking the contract
mock/smoke.ts              end-to-end check of the mock through the contract
```

## Run

- `make dev` — Tauri window with the embedded real backend.
- Without hardware: `pnpm mock` (mock backend on `ws://127.0.0.1:4800/ws`) then `pnpm dev`
  and open the printed URL in a browser.
- `make frontend-check` — `svelte-check`, `vite build`, mock type-check.

Types come from `contract/` via `make generate` (`@bufbuild/protoc-gen-es`).
